ESP32 Smart Power Monitoring & Control
An ESP32-based IoT power monitoring and control system using PZEM-004T, Blynk, and relay modules.

Features
- Real-time voltage, current, power, and energy monitoring
- Frequency and power factor monitoring
- Blynk mobile dashboard
- Remote light and socket control
- Automatic relay state synchronization
- Power data updates every 2 seconds

Hardware
- ESP32
- PZEM-004T
- 2-channel relay module
- Light/load
- Socket/load
- Wi-Fi connection

Blynk Virtual Pins
Pin	Data
V0	Voltage
V1	Current
V2	Power
V3	Energy
V4	Frequency
V5	Power Factor
V6	Light Control
V7	Socket Control
